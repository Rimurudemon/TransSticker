# Placeholder Assets

The following assets are placeholders and should be replaced with actual images:

## Required Assets

1. **icon.png** (1024×1024 px)

   - App icon for Android
   - PNG format with transparency support

2. **adaptive-icon.png** (1024×1024 px)

   - Android adaptive icon foreground
   - Should have padding for safe area

3. **splash.png** (1284×2778 px recommended)

   - Splash screen image
   - Will be centered on the screen

4. **favicon.png** (48×48 px)
   - Web favicon (if using web export)

## Creating Assets

You can use tools like:

- [Figma](https://figma.com)
- [Canva](https://canva.com)
- [App Icon Generator](https://appicon.co)
